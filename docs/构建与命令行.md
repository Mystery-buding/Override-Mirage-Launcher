## 运行

```powershell
cd "D:\AI\Override Mirage Launcher"
dotnet build -c Release
.\bin\Release\net10.0-windows\OverrideMirageLauncher.exe
```

需要 .NET 10 桌面运行时（装有 .NET 10 SDK 即已具备）。

## 打包成单个 exe（像 PCL 那样双击即用）

```powershell
cd "D:\AI\Override Mirage Launcher"
.\publish.cmd
```

产物是 `dist\Override Mirage Launcher.exe`，自包含单文件（约 126 MB，已内含 .NET 10 运行时与 WPF），**目标机器不需要装 .NET**，双击就开。等价命令：

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -o dist
```

第一次运行会在 exe 旁边生成：

```
dist\
├─ Override Mirage Launcher.exe
├─ config.json        配置
├─ logs\              启动器日志
├─ installers\        Forge / NeoForge 官方安装器缓存
└─ .minecraft\        游戏本体（versions / libraries / assets / mods / saves）
```

启动时日志会打一份「目录一览」，把这些路径完整列出来：

```
[INFO] —— 目录一览 ——
[INFO]   程序目录   D:\AI\Override Mirage Launcher\dist
[INFO]   配置文件   D:\AI\Override Mirage Launcher\dist\config.json
[INFO]   日志目录   D:\AI\Override Mirage Launcher\dist\logs
[INFO]   游戏目录   D:\AI\Override Mirage Launcher\dist\.minecraft
[INFO]   版本目录   ...\.minecraft\versions
[INFO]   依赖库     ...\.minecraft\libraries
[INFO]   资源文件   ...\.minecraft\assets
[INFO]   模组目录   ...\.minecraft\mods
[INFO]   存档目录   ...\.minecraft\saves
```

> 游戏目录默认是 exe 同级的 `.minecraft`，想换地方到「设置 → 游戏目录」改即可（可以指向已有的整合包目录，启动器会复用里面的版本与资源）。
> 注意不要删 `dist\`，游戏存档与整合包都在里面。

## 命令行

```powershell
$exe = ".\bin\Release\net10.0-windows\OverrideMirageLauncher.exe"

& $exe --selftest                                   # 链路自检（三个 Modrinth 来源的搜索/下载 + 正版登录通道）→ selftest.log
& $exe --install 1.21.4                             # 无界面安装原版
& $exe --installloader Fabric 1.21.4 0.16.9         # 只装加载器（原版已存在时）
& $exe --combo 26.3 Fabric 0.20.1 "26.3-Fabric"     # 一体化安装：本体 + 加载器 → 1 个整合包
& $exe --smokelaunch 1.21.4 Mirage                  # 真实启动并观察 25 秒
& $exe --uitest                                     # 界面自检：等首屏加载后切页 → uitest.log
& $exe --mslogin                                   # 正版登录逐步诊断（写到 mslogin.log，自动打开）
& $exe --resetaccount                              # 清掉本机正版账号（把启动器拷给别人之前先跑一次）
& $exe --exporticons                               # 导出方块图标到 images/blocks → grass/command/dirt.png
& $exe --exporticons D:\my-icons                   # 指定导出目录
```

> 重新编译前需要先关掉正在运行的启动器，否则 exe 被占用会导致 MSB3027。
